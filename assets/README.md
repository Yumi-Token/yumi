# 로고

원본은 발행자가 실제 사진을 그림으로 옮긴 것이고, 여기 있는 것은 **얼굴만 잘라낸 것**입니다.

| 파일 | 용도 | 크기 |
|---|---|---|
| `yumi-logo-256.png` | 토큰 리스트·CoinGecko 표준 규격 | 256×256 |
| `yumi-logo-512.png` | 소셜·문서 | 512×512 |
| `yumi-logo-64.png` | **지갑에서 실제로 보이는 크기** | 64×64 |
| `yumi-face.png` | 배경 없는 원본 크롭 | 360×360 |

전부 `tight` 크롭입니다. `full` 버전은 저장소에 넣지 않았습니다 —
**둘 다 두면 나중에 어느 게 공식인지 알 수 없게 됩니다.**

**`yumi-logo-64.png`는 256에서 축소해 만들었습니다.** `tight` 원본에 64px가 없었습니다.
