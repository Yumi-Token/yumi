# 채널 FAQ — 준비된 답

**압박이 있는 순간에 즉흥으로 답하는 게 가장 위험합니다.** 미리 써두고 복사해 씁니다.

게시물 원본은 [`CHANNELS.md`](CHANNELS.md)에 있습니다. 이 문서는 **대응 매뉴얼**입니다.

> ⚠️ **아직 메인넷 토큰이 없습니다.** 주소를 말해야 하는 답에는
> **반드시 「테스트넷(Base Sepolia)이고 가치가 없다」를 붙이세요.**

---

**압박이 있는 순간에 즉흥으로 답하는 게 가장 위험합니다.** 미리 써두고 복사해 쓰세요.

### 「미리 살 수 있나요?」

```
사전 판매는 하지 않습니다. 예외 없습니다.

방법이 어려우시면 그건 얼마든지 도와드릴게요.
다만 제가 돈을 받고 토큰을 보내드리는 건 하지 않습니다.
```

**이유를 길게 설명하지 마세요.** 설명이 길면 협상 여지가 있어 보입니다.

### 「언제 나오나요?」

```
날짜를 말하지 않습니다.

지키지 못한 계획은 나중에 사기의 근거로 쓰입니다.
그래서 날짜가 박힌 계획은 아예 만들지 않기로 했습니다.
나오면 기록에 적습니다.
```

### 「얼마까지 오를까요?」 / 「이거 사면 돈 되나요?」

```
답하지 않습니다.

제가 그 얘기를 시작하는 순간 이 프로젝트는 다른 게 됩니다.
가격은 시장이 정하고, 저는 기록을 씁니다.
```

### 「에어드랍 있나요?」

```
없습니다. 기본 설계에서 제외했습니다.

공짜 물량은 곧 팔 사람만 데려오고,
지금 규모에서는 1인당 커피 한 잔 값도 안 됩니다.
하게 된다면 대상 기준과 명단을 먼저 공개한 뒤에 합니다.
```

### 「개발자 물량이 얼마나 되나요?」

```
창업자 20%, 장기 재고 65%, 운영 10%, 근거리 5%입니다.

중요한 건 비율이 아니라 얼마나 빨리 움직일 수 있느냐인데,
예고 없이 움직일 수 있는 건 총량의 1%이고 시간이 지나도 그대로입니다.
나머지는 전부 7일 전에 공개됩니다.

그 1%가 시장에서 어떤 크기인지는 직접 계산하실 수 있습니다.
수량(1,000,000)과 초기 유동성 구간표가 전부 공개돼 있습니다:
https://github.com/Yumi-Token/yumi/blob/main/docs/TOKENOMICS.md

제 계산을 믿는 것보다 직접 해보시는 쪽이 낫습니다.
```

### 「밈코인인가요?」

```
이름은 제 고양이에서 땄습니다. 4년째 같이 삽니다.

밈코인이냐 아니냐는 제가 정할 수 있는 게 아니라고 생각합니다.
다만 여기서 가격 얘기는 하지 않고, 수익도 약속하지 않습니다.
제가 하는 건 매주 기록을 남기는 것 하나입니다.
```

**「밈코인이 아닙니다」라고 단정하지 마세요.** 판정할 기준이 없어서
나중에 「이건 밈코인 아니냐」는 소모적인 논쟁만 남습니다. (D-027)
**하는 것과 안 하는 것을 말하는 쪽이 확인 가능합니다.**

### 「러그풀 아닌가요?」

```
의심하시는 게 맞습니다. 그래서 확인할 수 있게 만들어뒀습니다.

- 추가 발행 함수가 없습니다 — 약속이 아니라 코드에 없습니다
- 소유자 권한이 없습니다 — 일시정지, 블랙리스트, 강제 회수 전부 불가능합니다
- 유동성을 빼려면 7일 전에 공개 예약을 걸어야 합니다

다만 완벽하지 않습니다. 못 막는 것도 문서에 그대로 적어뒀습니다.
「코드가 강제하는 것」과 「제 약속인 것」을 나눠서 적어둔 게 그 부분입니다:
https://github.com/Yumi-Token/yumi/blob/main/docs/TOKENOMICS.md
```

**마지막 문단을 빼지 마세요.** 완벽하다고 말하는 순간 신뢰를 잃습니다.

### 「어디서 사나요?」 — **지금은 이렇게 답합니다**

```
아직 살 수 없습니다. 메인넷 토큰이 없습니다.

지금 공개된 주소는 전부 테스트넷(Base Sepolia)이고 아무 가치가 없습니다.
「유미 코인」이라며 주소를 건네는 사람이 있으면 전부 사칭입니다.

메인넷에 올리면 여기와 저장소에 동시에 올립니다.
그 전에는 어떤 주소도 공식이 아닙니다.
```

**이 답을 발행 전까지 씁니다.** 아래는 발행 후에 바꿔 쓸 것입니다.

### 「어디서 사나요?」 (발행 후에만)

```
공식 주소: [주소]
확인: [Basescan 링크] · [WALLETS.md 링크]

Base 체인이라 한국에서 접근이 쉽지 않습니다. 경로는 여기 정리해뒀습니다: [가이드]
수수료가 고정이라 소액은 비중이 커집니다. 최소 [X]원 이상을 권합니다.

살 수 없어도 기록은 전부 무료로 보실 수 있습니다.
```
