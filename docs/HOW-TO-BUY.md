## 🔴 국내에서 오는 경로 — 브릿지가 반드시 낍니다

**업비트·빗썸에서 Base로 바로 못 보냅니다.** 이 부분이 가장 많이 막히는 곳입니다.

| | |
|---|---|
| 국내 거래소의 ETH 출금 | **이더리움 네트워크 고정** |
| Base로 직접 출금 | ❌ 안 됩니다 |

### 실제 경로

```
① 국내 거래소에서 원화 → ETH
② 이더리움 네트워크로 개인 지갑에 출금        ← 출금 수수료
③ bridge.base.org 에서 Base 로 넘기기         ← L1 가스가 듭니다 (비쌉니다)
④ Base 에서 ETH → USDC 스왑
⑤ USDC 로 YUMI 매수
```

**③이 가장 비쌉니다.** 이더리움 L1 가스라 시점에 따라 수만 원까지 갑니다.
**넘길 금액이 작으면 브릿지 비용이 더 클 수 있습니다.** 미리 계산해 보세요.

### ⚠️ AERO를 사서 Base로 보내는 함정

국내 거래소에 **Base 네트워크로 출금되는 토큰**(AERO 등)이 있습니다. 그걸로 우회하려는 분이 계신데 —

**Base의 가스는 ETH로 냅니다.** AERO만 들고 오면 **스왑조차 못 합니다.**
가스로 쓸 ETH가 Base에 조금이라도 있어야 합니다.

> 이건 Base만의 문제가 아닙니다. **Arbitrum·Optimism도 같습니다.**

### 해외 거래소를 쓰신다면

코인베이스·바이낸스 등은 **Base로 직접 출금**이 됩니다. 그 경우 ②③이 통째로 빠집니다.
다만 국내에서 해외 거래소로 보내는 것 자체가 별개 문제라, 여기서는 다루지 않습니다.

## 사는 곳

**중앙화 거래소에는 없습니다.** Uniswap v3 풀 하나뿐입니다.

### 🔴 유니스왑 공식 화면에서는 지금 안 됩니다 (2026-08-27 확인)

직접 해봤습니다. `USDC → YUMI` 로 토큰은 찾지만 **금액을 넣으면 `0` 이 나옵니다.**

**풀이 고장난 게 아닙니다.** 같은 시각 온체인 견적은 정상입니다.

| | $100 넣었을 때 |
|---|---|
| 유니스왑 화면 | **0 YUMI** |
| 온체인 Quoter | **185,261 YUMI** |
| KyberSwap | **185,263 YUMI** |

**이유** — 아직 **체결이 0건**이라 집계 쪽에 YUMI 가격이 없습니다.
유니스왑 화면이 YUMI 를 `US$0` 로 표시하고, **가치가 0인 풀은 라우터가 후보에서 거릅니다.**
첫 거래가 없어서 가격이 없고, 가격이 없어서 화면에서 거래가 안 되는 구조입니다.

🔴 **이게 바뀔지 우리가 정하지 못합니다.** 그래서 「나중에는 됩니다」라고 쓰지 않습니다.
**지금 되는 경로를 적어둡니다.**

### 되는 경로 ① — KyberSwap (견적까지 확인함)

애그리게이터는 집계 가격이 아니라 **체인을 직접 읽어서** 경로를 찾습니다.

```
https://kyberswap.com/swap/base
```

🔴 **KyberSwap 은 주소를 URL 로 못 받습니다.** 화면에서 직접 넣으셔야 합니다.

```
① 위 주소로 들어갑니다 (체인이 Base 인지 확인)
② 받을 토큰 칸을 눌러 아래 주소를 붙여넣습니다
   0xbDD3f6586093d5ec287d902A2F01A681c8131189
③ 파는 토큰을 USDC 로 둡니다
```

2026-08-27 확인한 견적입니다. **경로가 우리 풀 하나**(`0xaC130b30…4E3d`)로만 잡힙니다.

| 넣는 돈 | 받는 개수 | 개당 |
|---|---|---|
| $10 | 19,426 | $0.00051478 |
| $50 | 95,077 | $0.00052589 |
| $100 | 185,264 | $0.00053977 |
| $500 | 768,471 | $0.00065064 |

**금액이 커질수록 개당 가격이 오릅니다.** 이건 정상이고, 유동성이 구간으로 깔려 있기 때문입니다.

### 되는 경로 ② — Matcha (토큰은 찾습니다)

이쪽은 **주소를 URL 로 받습니다.** 눌러서 바로 들어가집니다.

```
https://matcha.xyz/swap?buyAddress=0xbdd3f6586093d5ec287d902a2f01a681c8131189&buyChain=8453&sellAddress=0x833589fcd6edb6e08f4c7c32d4f71b54bda02913&sellChain=8453
```

토큰 정보만 보시려면 이쪽입니다.

```
https://matcha.xyz/tokens/base/0xbdd3f6586093d5ec287d902a2f01a681c8131189
```

⚠️ **`USDC → YUMI` 로 채워지는 것까지는 확인했지만, 견적 숫자까지는 확인하지 못했습니다.**
Matcha 도 아직 YUMI 가격을 모릅니다(`-` 로 표시). **숫자가 안 나오면 ①을 쓰세요.**

🔴 **어느 쪽이든 주소를 직접 붙여넣으세요.** 검색으로 고르면 같은 이름의 다른 토큰이 잡힐 수 있습니다. (D-027)
**열린 화면의 주소가 위와 같은지 눈으로 확인하세요.**

### 표시되는 「현재가」를 그대로 믿지 마세요

풀의 현재 틱이 **유동성이 깔린 구간보다 199틱 위**에 있습니다.
그래서 화면에 뜨는 값(`$0.00049690`)과 **실제 첫 체결가**(`$0.00050689`)가 다릅니다.

**첫 매수자가 그 사이를 지나갈 때는 아무것도 교환되지 않습니다** — 그 구간에 물량이 없기 때문입니다.
손해도 이득도 아니고, **첫 체결은 언제나 $0.00050689 부터** 시작합니다.

이건 구간을 한 칸 옮기면서 생긴 틈입니다. 그 판단은 [`log/`](../log/) 에 적혀 있습니다.
