## 🔴 국내에서 오는 경로 — 브릿지가 반드시 낍니다

**업비트·빗썸에서 Base로 바로 못 보냅니다.** 이 부분이 가장 많이 막히는 곳입니다.

| | |
|---|---|
| 국내 거래소의 ETH 출금 | **이더리움 네트워크 고정** |
| Base로 직접 출금 | ❌ 안 됩니다 |

### 실제 경로

```
① 국내 거래소에서 원화 → ETH
② 이더리움 네트워크로 개인 지갑에 출금        ← 출금 수수료
③ bridge.base.org 에서 Base 로 넘기기         ← L1 가스가 듭니다 (비쌉니다)
④ Base 에서 ETH → USDC 스왑
⑤ USDC 로 YUMI 매수
```

**③이 가장 비쌉니다.** 이더리움 L1 가스라 시점에 따라 수만 원까지 갑니다.
**넘길 금액이 작으면 브릿지 비용이 더 클 수 있습니다.** 미리 계산해 보세요.

### ⚠️ AERO를 사서 Base로 보내는 함정

국내 거래소에 **Base 네트워크로 출금되는 토큰**(AERO 등)이 있습니다. 그걸로 우회하려는 분이 계신데 —

**Base의 가스는 ETH로 냅니다.** AERO만 들고 오면 **스왑조차 못 합니다.**
가스로 쓸 ETH가 Base에 조금이라도 있어야 합니다.

> 이건 Base만의 문제가 아닙니다. **Arbitrum·Optimism도 같습니다.**

### 해외 거래소를 쓰신다면

코인베이스·바이낸스 등은 **Base로 직접 출금**이 됩니다. 그 경우 ②③이 통째로 빠집니다.
다만 국내에서 해외 거래소로 보내는 것 자체가 별개 문제라, 여기서는 다루지 않습니다.

## 사는 곳

**중앙화 거래소에는 없습니다.** Uniswap v3 풀 하나뿐입니다.

### 유니스왑에서 됩니다 (2026-08-27 확인)

```
https://app.uniswap.org/swap?chain=base&outputCurrency=0xbDD3f6586093d5ec287d902A2F01A681c8131189
```

같은 시각 세 경로가 전부 같은 숫자를 냅니다. $100 기준입니다.

| 경로 | 받는 개수 |
|---|---|
| 유니스왑 화면 | 184,463 |
| 온체인 Quoter | 184,463 |
| KyberSwap | 184,465 |

**오늘 오전까지는 안 됐습니다.** 같은 화면에 $100 을 넣으면 `0` 이 나왔습니다.
체결이 0건이라 집계 쪽에 YUMI 가격이 없었고, **가치가 0인 풀은 라우터가 후보에서 걸렀기** 때문입니다.
**첫 두 건이 체결되면서 풀렸습니다** — 그 거래는 [`WALLETS.md`](WALLETS.md) 에 해시로 적어뒀습니다.

🔴 **이건 우리가 고친 것이 아닙니다.** 누군가 샀기 때문에 풀린 것이고,
**다시 막힐지 우리가 정하지 못합니다.** 막히면 아래를 쓰세요.

### 막혔을 때 — KyberSwap

애그리게이터는 집계 가격이 아니라 **체인을 직접 읽습니다.**

```
https://kyberswap.com/swap/base
```

🔴 **주소를 URL 로 못 받습니다.** 들어가서 받을 토큰 칸에 직접 붙여넣으세요.

```
0xbDD3f6586093d5ec287d902A2F01A681c8131189
```

**Matcha** 는 주소를 URL 로 받습니다. 첫 두 건이 실제로 이 경로(0x Settler)로 체결됐습니다.

```
https://matcha.xyz/tokens/base/0xbdd3f6586093d5ec287d902a2f01a681c8131189
```

🔴 **어느 쪽이든 열린 화면의 주소가 위와 같은지 눈으로 확인하세요.** (D-027)

### 표시되는 「현재가」를 그대로 믿지 마세요

풀의 현재 틱이 **유동성이 깔린 구간보다 199틱 위**에 있습니다.
그래서 화면에 뜨는 값(`$0.00049690`)과 **실제 첫 체결가**(`$0.00050689`)가 다릅니다.

**첫 매수자가 그 사이를 지나갈 때는 아무것도 교환되지 않습니다** — 그 구간에 물량이 없기 때문입니다.
손해도 이득도 아니고, **첫 체결은 언제나 $0.00050689 부터** 시작합니다.

이건 구간을 한 칸 옮기면서 생긴 틈입니다. 그 판단은 [`log/`](../log/) 에 적혀 있습니다.
