## 2. 저장소를 공개하기 전에

- [ ] `.env`가 **한 번도 커밋된 적 없는지** — `git log --all --full-history -- .env`
      (결과가 비어 있어야 합니다. 나오면 그 키는 즉시 폐기하고 새로 만드세요.
       히스토리에서 지워도 이미 노출된 것으로 간주합니다)
- [ ] `git log -p --all | grep -i "0x[0-9a-f]\{64\}"` — 64자리 16진수가 커밋에 없는지
- [ ] `.gitignore`에 `.env`, `cache/`, `out/`, `broadcast/**/dry-run/`
      — `broadcast/`를 통째로 빼지 않습니다. 배포 트랜잭션 기록은 **일부러 커밋합니다**

        dry-run 결과만 제외합니다 — `.gitignore` 주석에 같은 이유가 적혀 있습니다
- [ ] 공개하면 **과거 커밋 전부**가 같이 공개된다는 것 — 초기 시행착오까지
- [ ] **의존성이 위변조되지 않았는가** — `git submodule status`에 `+`가 없고
      커밋 해시가 공식 태그와 같은가 ([`SECURITY.md`](SECURITY.md) 「저장소와 의존성이 바뀌지 않았는지」)
